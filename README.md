# ⚡ AI-Based Electricity Usage Forecasting System

### Smart Energy | Climate Tech | Machine Learning Project

---

## 🅰️ Project Overview

This project builds an **AI-powered electricity usage forecasting system** that predicts future energy consumption using historical data.

It helps to:

* Optimize energy usage ⚡
* Reduce energy wastage 💸
* Support smart grid systems 🏙️
* Improve sustainability 🌱

---

## ❗ Problem Statement

### 🔥 Unpredictable Energy Demand

Power systems often struggle with:

* Overconsumption → Blackouts ⚡
* Underutilization → Energy wastage 💸

### 💡 Solution

This project uses **Machine Learning** to:

* Predict future electricity usage
* Help plan energy distribution
* Support smart cities & climate technology

---

## 🌍 Industry Relevance

This system is used in:

* Smart Grids
* Smart Homes
* Renewable Energy Systems
* Energy Management Systems
* IoT-based monitoring

---

## 🅱️ Selected Approach

* Random Forest Regression 🌳
* Time-based feature engineering ⏱️
* CSV dataset

---

## 🅲 Architecture

```text
Input Data (Energy Usage CSV)
        ↓
Data Preprocessing
        ↓
Feature Engineering (Hour, Day, Month)
        ↓
Model Training (Random Forest)
        ↓
Prediction
        ↓
Visualization
        ↓
Output (Forecast Graph)
```

# 🅴 🧑‍💻 How to Run This Project (Beginner Friendly)

Follow these steps carefully 👇

---

## ✅ Step 1: Install Python

Download and install Python from official website.

👉 While installing:
✔ Tick **"Add Python to PATH"**

Check installation:

```bash
python --version
```

---

## ✅ Step 2: Open Project Folder

Open your project folder:

```text
F:\AI-Energy-Forecasting
```

Open it in **VS Code**

---

## ✅ Step 3: Open Terminal

In VS Code:

* Click **Terminal → New Terminal**

Shortcut:

```text
Ctrl + `
```

---

## ✅ Step 4: Create Virtual Environment

```bash
python -m venv venv
```

---

## ✅ Step 5: Activate Virtual Environment

```bash
venv\Scripts\activate
```

You will see:

```text
(venv) F:\AI-Energy-Forecasting>
```

---

## ✅ Step 6: Install Required Libraries

```bash
pip install pandas numpy scikit-learn matplotlib
```

---

## ✅ Step 7: Run the Project

```bash
python main.py
```
